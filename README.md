## Superficial white matter processing with the `SWiM` ##

[`SWiM`]() is developed by the [MICA Lab](https://mica-mni.github.io) at McGill University, [The Neuro](https://www.mcgill.ca/neuro/), and the McConnell Brain Imaging Centre ([BIC](https://www.mcgill.ca/bic/)). 
> The main goal of this pipeline is to provide a robust computational framework for studying SWM organization and fibre architecture from MRI data.
> `SWiM` integrates established software dependencies with tools developed in our laboratory.
> The pipeline supports the processing of T1-weighted, quantitative MRI, and diffusion-weighted MRI data for the characterization of SWM organization and fibre architecture.
